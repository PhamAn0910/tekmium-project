# Tekmium RAG Project

A Retrieval-Augmented Generation (RAG) project that combines document retrieval with generative AI capabilities.

## Overview

This project implements a RAG system that enables intelligent document-based question answering and information retrieval by leveraging both retrieval and generation mechanisms.

## Features

- Document retrieval and indexing
- Generative AI integration
- Context-aware responses

## Getting Started

### Prerequisites

- Python 3.8+
- Required dependencies (see requirements below)

### Installation

```bash
git clone <repository-url>
cd tekmium-project
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```

## Project Structure

- `/src` - Source code
- `/data` - Data and documents
- `/tests` - Test files
- `/docs` - Documentation
